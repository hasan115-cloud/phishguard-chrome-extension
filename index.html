📋 Real Chrome Installation Instructions (Step-by-Step)
1 Download & Extract

Click DOWNLOAD EXTENSION above to download FortiNex-Extension.zip. Extract the archive onto your computer. You will see a folder named FortiNex-Extension containing manifest.json.

2 Open Extensions Page

Open Google Chrome and navigate to: chrome://extensions
(Or click ⋮ Menu → Extensions → Manage Extensions)

3 Enable Developer Mode

In the top-right corner of the Extensions page, toggle the switch labeled Developer mode to ON.

4 Load Unpacked

Click the Load unpacked button on the top-left toolbar. In the file picker dialog, select the extracted FortiNex-Extension folder.

5 Enrolled & Protected!

FortiNex is now active! It automatically registers with this server, acquires a unique client ID, begins sending 30s heartbeats, and intercepts navigation. Verify it in the Enrolled Systems tab.
